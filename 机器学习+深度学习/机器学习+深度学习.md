## **<mark>np.linspace()</mark>**

作用：用来**生成等间隔的数字序列**。

### **基本格式**

```
np.linspace(start, stop, num)
```

参数含义：

| 参数      | 含义     |
| ------- | ------ |
| `start` | 起始值    |
| `stop`  | 结束值    |
| `num`   | 生成多少个数 |

它会在 `start` 和 `stop` 之间**均匀取 `num` 个点**。

注意：start通常不取0，通常是因为函数在 `x=0` 处可能没有定义。

还可以在后面添加参数：endpoint=True：是否包含终点

`retstep`：是否返回步长

`dtype`：指定数据类型

`axis`：多维数组时指定轴

```
#补充：如果想指定步长，用：

np.arange(start, stop, step)

#如果想指定点的数量，用：

np.linspace(start, stop, num)
```

| 写法                      | 含义          |
| ----------------------- | ----------- |
| `np.linspace(10)`       | 0~10，默认50个点 |
| `np.linspace(0,10)`     | 0~10，默认50个点 |
| `np.linspace(0,10,100)` | 0~10，100个点  |
| `np.linspace(10,20,5)`  | 10~20，5个点   |

## **<mark>逻辑与或非</mark>**

| NumPy函数               | 符号       |
| --------------------- | -------- |
| `np.logical_and(a,b)` | `a & b`  |
| `np.logical_or(a,b)`  | `a \| b` |
| `np.logical_not(a)`   | `~a`     |

```
import numpy as np
import matplotlib.pyplot as plt

data=2*np.random.rand(10000,2)-1
print(data)
x=data[:,0]  #:表示这一维全部取
y=data[:,1]
idx=x**2+y**2<1
hole=x**2+y**2<0.25
idx=np.logical_and(idx,~hole)    #idx = 大圆内部 AND 不在小圆内部
plt.plot(x[idx],y[idx],'go',markersize=1)
plt.axis('equal')
plt.show()
```

## **<mark>np.set_printoptions()</mark>**

### **基本格式：**

```
np.set_printoptions(参数)
```

### **作用：**

> 设置 NumPy 数组输出时的显示规则。

### **参数**

#### edgeitems=5000

这个参数控制：

> 数组太长时，显示开头和结尾多少个元素。

默认：

```
edgeitems=3
```

例如：

```
a=np.arange(20)
print(a)
#可能：
[ 0  1  2 ... 17 18 19]
```

#### suppress=True

这个参数控制：

> 是否禁止科学计数法显示。

suppress=True是禁止使用科学计数法显示

#### precision：控制小数位数

```
np.set_printoptions(precision=2)
#显示：
[0.12 0.56 0.78]
```

#### threshold：控制多少元素后省略

```
np.set_printoptions(threshold=10000)
#表示：
超过10000个元素才省略。
```

#### linewidth：控制一行显示宽度

```
np.set_printoptions(linewidth=200)
#让一行显示更多内容。
```

### 示例：

```
import numpy as np
import matplotlib.pyplot as plt

p=np.random.rand(10000)

print(p.shape)
```

## **<mark>布尔索引</mark>**

```
d=
[
-1.2,
0.3,
0.8,
-0.5,
1.5
]
```

判断：

```
d<0.5
```

得到：

```
[
True,
True,
False,
True,
False
]
```

| 元素   | 是否<0.5 |
| ---- | ------ |
| -1.2 | True   |
| 0.3  | True   |
| 0.8  | False  |
| -0.5 | True   |
| 1.5  | False  |

d[d<0.5]NumPy 会理解为：

> 只选择 True 对应的位置。

所以：

```
d[d<0.5]
```

得到：

```
[
-1.2,
0.3,
-0.5
]
```

### **示例**

```
import numpy as np
import matplotlib.pyplot as plt

d=np.random.randn(10)
d[d<0.5]=0.5   #布尔索引（Boolean Indexing）+ 批量赋值
print(d)
```

## **<mark>plt.stem()</mark>**

`plt.stem()` 是 **Matplotlib 中用于绘制茎叶图（Stem Plot，杆状图）** 的函数。

作用：`plt.stem()` 会把每个数据点用一根竖线连接到水平轴，并在顶端画一个点。

### **基本格式**

```
plt.stem(
    x,
    y,
    linefmt=None,
    markerfmt=None,
    basefmt=None
)
```

x：横坐标

y：纵坐标

linefmt：设置竖线样式，例如：

| 代码      | 含义   |
| ------- | ---- |
| `'r-'`  | 红色实线 |
| `'b--'` | 蓝色虚线 |
| `'g:'`  | 绿色点线 |

markerfmt：设置顶部点的样式，例如：

| 符号  | 形状  |
| --- | --- |
| `o` | 圆   |
| `*` | 星号  |
| `+` | 加号  |
| `s` | 方形  |

basefmt：设置底部水平线，后面可以跟颜色设置

与其他相似函数比较：

- `plot()` → 连续曲线
- `scatter()` → 散点
- `stem()` → 离散数据的“杆状图”（点+连接线）

## **<mark>plt.title()</mark>**

`plt.title()` 是 **Matplotlib 中用于给图像添加标题** 的函数。

### **基本格式**

```
plt.title(
    label,
    fontdict=None,
    loc=None,
    pad=None,
    **kwargs
)
```

| 参数       | 作用                              |
| -------- | ------------------------------- |
| label    | 标题文字（字符串形式）                     |
| fontdict | 设置字体                            |
| loc      | 标题位置（有三个值：默认是center，left，right） |
| pad      | 标题距离图像的距离（数字越大，标题离图越远。默认pad=6）  |
| fontsize | 字体大小                            |
| color    | 字体颜色                            |

与其他相似函数比较：

| 函数           | 作用     |
| ------------ | ------ |
| plt.title()  | 整个图的标题 |
| plt.xlabel() | x轴名称   |
| plt.ylabel() | y轴名称   |

## **<mark>plt.grid()</mark>**

`plt.grid()` 是 **Matplotlib 中用于显示网格线（grid lines）** 的函数。

`plt.grid()` 会在图像背景上添加横向和纵向的参考线，让数据的位置更容易观察。

plt.grid(True)等价于plt.grid(b=True):打开网格。

plt.grid(axis="y"):只显示横向网格

plt.grid(axis="x"):只显示纵向网格

plt.grid(axis="both"):横纵都有（默认）

### **设置网格线样式**

```
plt.grid(
    color="gray",
    linestyle="--",
    alpha=0.5
)plt.grid(
    color="gray",
    linestyle="--",
    alpha=0.5
)
```

| 参数                  | 作用    |
| ------------------- | ----- |
| color               | 颜色    |
| linestyle(可以简化写成ls) | 线型    |
| alpha               | 透明度   |
| linewidth           | 网格线粗细 |

| alpha值 | 效果       |
| ------ | -------- |
| 0      | 完全透明，看不见 |
| 0.3    | 很淡       |
| 0.5    | 半透明      |
| 0.8    | 比较明显     |
| 1      | 完全不透明    |

### **示例：**

```
plt.grid(
    visible=True,
    linestyle="--",
    linewidth=1,
    alpha=0.5
)
```
